**Roles used everywhere.** Client roles come from `config/roles.json`; Agentry staff can do everything, and every staff action is audited.

| Role | In one line |
|---|---|
| **Agentry admin / staff** | Sells, sets up and runs clients from Agentry HQ; can open any client's portal |
| **Owner** | The client's boss: everything in their portal, including team, billing and connections |
| **Manager** | Day-to-day work and settings; no team or billing |
| **Front desk** | Works the queue: approves drafts, replies, books |
| **Finance** | Invoices, payments, statements |
| **Viewer** | Reads reports only |

**Who gets which Needs-you card.** Cards wait for anyone allowed to act on them, unless someone is named:
1. **Assigned by hand** on the card (the person gets an email). Never changed by rules.
2. **Inbox routing:** everything arriving at one mailbox goes to one person (Connections → the inbox).
3. **Client rule** (Invoices → *Who handles each client*): every card about that client goes to one person. It only
   covers the cards that person can work: a client given to Finance sends Finance their invoice cards, while their
   emails stay with the people who handle conversations.
4. **Agent rule** (Automations → the agent → *Who handles its cards*): everything that agent creates goes to one person.

Rules are set by owners and managers (and Agentry). New cards follow them straight away; cards already waiting are
re-decided when a rule changes. Assigned cards show "for <name>" and appear under Needs you → **Mine**.

**How it's tested with every login.** Two checks, both run before a release:
1. `cd backend && uv run pytest tests/test_role_matrix.py`: every portal endpoint called by owner, manager, front desk,
   finance, viewer and Agentry staff on a client with every agent (nothing errors; each role gets the page or a clean
   refusal), and on clients with one agent each (sections an agent doesn't bring are hidden, Agentry included).
2. `uv run --project backend python infra/smoke/crawl_portal.py`: signs in as every demo login, including the
   **Every Agent Co** logins below, and opens every portal page; a crash fails the run.

Every Agent Co (local demo, all 39 agents live; password `agentry-demo-123`): `owner@`, `manager@`, `frontdesk@`,
`finance@`, `viewer@everyagent.example`. Create it with `pnpm --filter @agentry/dashboard seed:auth` then
`cd backend && uv run agentry seed-every-agent`.
